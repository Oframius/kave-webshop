# Bean & Bloom – kávés webshop mintaprojekt

Reszponzív, statikus HTML/CSS/JavaScript kávés weboldal egyetemi csapatprojekthez.

## Funkciók
- 15 kávé két kategóriában (klasszikus, ízesített)
- Keresés és kategóriaszűrés
- Rámutatáskor megjelenő termékleírás (mobilon mindig látható)
- Kosár darabszámmódosítással és böngészőben tárolással
- Modern, mobilbarát megjelenés

## Indítás
Nyisd meg az `index.html` fájlt böngészőben. Nincs szükség telepítésre.

## GitHub Pages
1. GitHub → New repository → adj meg nevet, válaszd a Public opciót.
2. Add file → Upload files → töltsd fel az `index.html`, `README.md` és `.nojekyll` fájlokat (a ZIP-et előbb ki kell csomagolni).
3. Commit changes.
4. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.
5. Megjelenik az oldal GitHub Pages címe.

## Fontos
Ez nem valódi webshop: nincs szerver, bejelentkezés, valódi rendelésfeldolgozás vagy fizetés. A termékárak szemléltető árak. Az allergénleírások nem teljes körű, ellenőrzött összetevőlisták. A termékek és árak az `index.html` alján a `coffees` listában módosíthatók.
